## gui-for-zapret-fs 0.2.1

Исправление запуска службы Zapret. Работа исправления подтверждена пользователем.

- Неверный путь WinDivert исправляется перед запуском только для остановленного драйвера. Активные драйверы не изменяются.
- Программа ждёт запуска или остановки службы и обнаруживает немедленное завершение.
- При отказе запуска журнал показывает причину, включая сообщения Windows о WinDivert.
- Исправлено применение стратегии к существующей службе и отображение ошибок чтения её состояния.

Скачайте **gui-for-zapret-fs-win-x64-portable.zip** и распакуйте целиком в новую папку. Запускайте **gui-for-zapret-fs.exe**; папка **scripts** должна оставаться рядом. В архив включён новый обязательный сценарий **scripts/service-control.ps1**.

.NET 8.0.31 включён в EXE, отдельно устанавливать .NET не требуется. Сам Flowseal Zapret скачивается отдельно. Списки в папке Zapret сохраняются; при необходимости перенесите config.json из предыдущей папки GUI.

Проверено локально: сборка Release без предупреждений, 80 проверок C#, 11 проверок сценариев и 26 проверок управления службой с имитацией системных вызовов.

Файл .sha256 содержит контрольную сумму ZIP.
