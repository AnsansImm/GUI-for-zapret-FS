## gui-for-zapret-fs 0.2.2

Упрощена вкладка «Диагностика».

- Убрана кнопка «Перенести WinDivert»: перенос выполняется при обновлении Zapret.
- Кнопка «Включить TCP timestamps» теперь находится в карточке соответствующей проверки и появляется только при отключённых timestamps.
- После включения проверка запускается повторно. Если определить состояние не удалось, карточка сообщает об этом.

Скачайте **gui-for-zapret-fs-win-x64-portable.zip** и распакуйте целиком в новую папку. Запускайте **gui-for-zapret-fs.exe**; папка **scripts** должна оставаться рядом.

.NET включён в EXE, отдельно устанавливать его не требуется. Сам Flowseal Zapret скачивается отдельно. При необходимости перенесите config.json из предыдущей папки GUI.

Изменения диагностики проверены локально: сборка Release без предупреждений, 93 проверки C# и 16 проверок сценариев. Проверки не изменяют системные настройки. Проверка и сборка релиза выполняются автоматически в GitHub Actions.

Файл .sha256 содержит контрольную сумму ZIP.
