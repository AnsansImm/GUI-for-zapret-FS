## gui-for-zapret-fs 0.2.0

Новая версия на C# / Windows Forms вместо Rust.

- Тёмный интерфейс с единым оформлением всех разделов и тёмным заголовком Windows.
- Исправлены размеры карточек и порядок стратегий.
- Улучшен редактор списков: проверка адресов, комментарии, защита от конфликтов сохранения.
- Убраны лишние подтверждения; подтверждение осталось только у удаления службы.
- Исправлены углы карточек диагностики, добавлены иконка приложения и номер версии.

Скачайте **gui-for-zapret-fs-win-x64-portable.zip** и распакуйте целиком. Запускайте **gui-for-zapret-fs.exe**; оставьте папку **scripts** рядом. .NET 8.0.31 включён в EXE, отдельная установка .NET не нужна.

Сам Flowseal Zapret скачивается отдельно. При обновлении GUI пользовательские списки в папке Zapret сохраняются. При необходимости перенесите config.json из старой папки GUI.

Файл .sha256 содержит контрольную сумму архива.
