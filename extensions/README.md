# Расширение Zapret GUI

Исходники: `extensions/chromium` (Chrome, Opera, Edge), `extensions/firefox` (Firefox).
Помощник: `src/bin/zapret-native.rs`. Списки и транзакции: `src/list_store.rs`.
Регистрация: `src/browser_link.rs`. Сборка: `cargo build --release --offline`.

## Подключение Chrome / Opera / Edge

1. Оба файла `target/release/zapret-gui.exe` и `target/release/zapret-native.exe` должны оставаться рядом. Откройте GUI, выберите папку Zapret.
2. Откройте `chrome://extensions`, `opera://extensions` или `edge://extensions`.
3. Включите режим разработчика → «Загрузить распакованное расширение» → выберите папку `extensions/chromium` из этого проекта.
4. Скопируйте ID установленного расширения (32 буквы).
5. В GUI откройте «Браузеры», выберите Chrome / Opera либо Edge, вставьте ID и нажмите «Зарегистрировать подключение».
6. На обычном HTTP/HTTPS-сайте откройте расширение. Если нужно, закрепите его значок в браузере.

Для нескольких браузеров зарегистрируйте ID каждого: список разрешённых ID дополняется.
Opera использует Chrome-регистрацию Native Messaging согласно своей документации; эту связку нужно проверить в вашей версии браузера.

## Firefox (разработка)

1. Откройте `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `extensions/firefox/manifest.json`.
2. В GUI → «Браузеры» → Firefox → «Зарегистрировать подключение».
3. Откройте расширение на HTTP/HTTPS-сайте.

Временное дополнение удаляется при перезапуске Firefox. Для постоянной установки в обычном Firefox потребуется подписанный пакет Mozilla. Сейчас готова версия для локального тестирования, публикация не выполнялась.

## Поведение

- «Через Zapret» добавляет точный домен в `list-general-user.txt` и удаляет ту же запись из `list-exclude-user.txt`.
- «Исключить из Zapret» делает обратное. Регистр при сопоставлении игнорируется, дубли удаляются.
- Комментарии, wildcard и поддомены остаются. Общие списки Flowseal не меняются. Записи нормализуются к LF при изменении user-файла.
- Статус читается из файлов заново: не добавлен, обработка, исключение или конфликт в обоих user-листах. Это статус точной записи, а не итог всех правил Zapret.
- IP-адреса, localhost, служебные страницы браузера не поддерживаются. Международные домены браузер передаёт в punycode.
- Кнопка открытия программы пытается поднять уже открытое окно, иначе запускает GUI. Ограничения Windows могут помешать переводу фокуса.
- GUI не должен постоянно работать. Браузер запускает помощник для каждого запроса.
- Редактор проверяет внешние изменения и использует ту же блокировку, что и помощник. При несохранённых правках GUI конфликт нужно разрешить вручную, без перезаписи чужих изменений.
- Если user-лист после удаления последнего домена содержит только комментарии, добавляется штатный служебный домен `domain.example.abc`, чтобы список не остался без записей.

## Локальные данные

Регистрация создаёт JSON-манифесты в `browser-hosts` рядом с exe и значения HKCU NativeMessagingHosts текущего пользователя. Прав администратора не требуется. Конфигурация Zapret остаётся в `config.json` рядом с exe. После переноса exe нужно повторить регистрацию.

В папке lists создаётся `.zapret-gui.lock`; наличие этого файла само по себе не означает занятую блокировку. При изменении двух user-файлов временно создаётся `.zapret-gui-transaction.json`; при аварии он позволяет откатить незавершённую операцию при следующем обращении помощника или сохранении редактора.

Никакие данные не отправляются на внешний сервер. Расширение передаёт только домен и команду локальному помощнику. Полные адреса страниц, история и содержимое сайтов не читаются помощником.

## Удаление подключения

Удалите расширение через браузер. Регистрацию помощника можно удалить в редакторе реестра, удалив только подраздел `com.zapret_gui.lists` из:

- `HKCU\Software\Google\Chrome\NativeMessagingHosts`
- `HKCU\Software\Chromium\NativeMessagingHosts`
- `HKCU\Software\Microsoft\Edge\NativeMessagingHosts`
- `HKCU\Software\Mozilla\NativeMessagingHosts`

Файлы списков и config.json удалять не требуется.
