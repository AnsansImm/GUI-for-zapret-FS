# Changelog

## 0.2.0

- Перенос gui-for-zapret-fs с Rust на C# / Windows Forms (.NET 8).
- Единое оформление разделов, тёмный заголовок окна и минимальный размер окна без обрезания кнопок.
- Установка и управление службой, сортировка стратегий как в оригинале.
- Проверка доменов, IP, подсетей и диапазонов; поддержка комментариев и защита от конфликтов сохранения.
- Подтверждение только для удаления службы; кнопка удаления выделена красным.
- Исправление фона скруглённых карточек диагностики.
- Единое имя gui-for-zapret-fs, версия в заголовке и свойствах EXE, иконка из assets/app.ico.
- Портативный релиз в ZIP со встроенным .NET и необходимыми PowerShell-сценариями.
