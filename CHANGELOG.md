# Changelog

## 0.2.1

- Исправлен запуск службы при недействительном пути WinDivert: остановленный драйвер получает корректный путь; активный драйвер не изменяется.
- Запуск и остановка ожидают фактического состояния службы; немедленное завершение больше не отображается как успешный запуск.
- Ошибки запуска дополняются сообщениями Windows о Zapret и WinDivert.
- Применение стратегии использует системный механизм изменения службы вместо прямой записи команды в реестр.
- Ошибка чтения состояния службы больше не отображается как отсутствие службы.
- Добавлены 26 проверок управления службой без изменения реальной системы; новый сценарий включён в портативный архив.

## 0.2.0

- Перенос gui-for-zapret-fs с Rust на C# / Windows Forms (.NET 8).
- Единое оформление разделов, тёмный заголовок окна и минимальный размер окна без обрезания кнопок.
- Установка и управление службой, сортировка стратегий как в оригинале.
- Проверка доменов, IP, подсетей и диапазонов; поддержка комментариев и защита от конфликтов сохранения.
- Подтверждение только для удаления службы; кнопка удаления выделена красным.
- Исправление фона скруглённых карточек диагностики.
- Единое имя gui-for-zapret-fs, версия в заголовке и свойствах EXE, иконка из assets/app.ico.
- Портативный релиз в ZIP со встроенным .NET и необходимыми PowerShell-сценариями.
