# Zapret GUI

Экспериментальная независимая оболочка для Flowseal Zapret 1.10.4, Rust + egui, Windows x64.

## Запуск

Соберите `cargo build --release`, запустите `target/release/zapret-gui.exe` и выберите распакованную папку Zapret. Программа не изменяет service.bat или стратегии. Настройки приложения хранятся в config.json рядом с exe.

## Возможности 0.1

- Чтение состояния zapret и WinDivert.
- Запуск, остановка, установка/перенастройка и удаление службы zapret с запросом UAC.
- Выбор стратегии из файлов сборки; разворачивание BIN, LISTS, GameFilterTCP/UDP. Неизвестные переменные отклоняются.
- IPSet: режимы «По списку», «Отключён», «Любые IP», резервное копирование и обновление из Flowseal с проверкой IPv4/IPv6, подсетей и диапазонов. Обновление не переключает отключённый режим: новый список сохраняется в резервную копию.
- Настройка Game Filter и диапазонов портов. Для службы после изменения повторно примените стратегию.
- Редактор UTF-8 списков: фильтрация доменов, отдельные допустимые символы IPSet (IPv4/IPv6, подсети и диапазоны), комментарии # с любым текстом. Пробел разделяет записи, пустые строки удаляются. Внизу остаётся строка для ввода, курсор при открытии установлен в конец. Автосохранение через 400 мс, перед сменой файла/папки и закрытием окна. Внешние изменения проверяются перед записью; при ошибке переход и закрытие отменяются.
- Выбор активных fake-файлов Discord UDP и Game Filter UDP, определение текущего по содержимому, резервная копия .backup и восстановление. После замены требуется перезапуск Zapret.
- HTTP/TLS 1.2/TLS 1.3/ping в GUI: выбор стратегий, targets.txt, таймаут, прогресс, таблица и отдельная кнопка применения. Служба временно останавливается и восстанавливается без переустановки; IPSet не меняется. Отдельные winws из выбранной папки сохраняются в журнал, останавливаются и восстанавливаются с прежними параметрами. Процессы из других папок блокируют тест. DPI TCP 16–20 доступен в GUI: официальный набор dpi-checkers или свой хост, размер данных, HTTP/TLS-варианты и признак LIKELY_BLOCKED. IPSet временно очищается только в DPI-режиме, исходные байты сохраняются в журнале и восстанавливаются перед запуском исходного Zapret. Подробности передачи доступны при наведении на цель. Набор загружается до остановки Zapret.
- Отмена теста выполняется между ограниченными по времени проверками. Закрытие окна во время теста запрашивает отмену и ждёт завершения. Журнал test-run/journal.json позволяет восстановить состояние после аварии, результаты сохраняются в test-run/report.json; предыдущие запуски архивируются в test-report-* рядом с exe.
- Диагностика в GUI: файлы сборки, службы, winws, возможные конфликты, прокси, hosts и установленная стратегия. Проверка ничего не меняет, отчёт можно скопировать.

Установка включает TCP timestamps и автозапуск службы. Удаление удаляет только службу zapret: WinDivert и чужие процессы не затрагиваются. Проверки службы и установки на реальной системе пользователь выполняет отдельно.

- Проверка обновлений Flowseal: версия из service.bat, проверка официального version.txt в фоне, сравнение номеров и ссылка на страницу загрузки. Автоматическая установка не выполняется.

- Исправления из диагностики: запуск BFE и включение глобального TCP timestamps с подтверждением, UAC и повторной диагностикой. Автоматических исправлений без нажатия кнопки нет.

- Расширения Chromium (Chrome/Opera/Edge) и Firefox: две кнопки user-листов, чтение состояния, открытие GUI. Подключение через Native Messaging без сервера и трея. Инструкция: [extensions/README.md](extensions/README.md). Рядом с GUI необходим zapret-native.exe.

## Ограничения

Это первый прототип, не полный перенос service.bat. Исправления по результатам диагностики, обновление самой сборки ещё не реализованы. Служба использует абсолютные пути: после переноса папки повторно примените стратегию. Отчёты исходного теста находятся в utils/test results.
